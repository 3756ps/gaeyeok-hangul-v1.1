# 개역한글 v1.1

> **현대적 운율을 갖춘 완전 개방형 낭독용 표준역 (Modern Public Domain Version)**

본 프로젝트는 저작권 장벽 없이 누구나 자유롭게 활용, 가공, 배포할 수 있는 오픈소스 성경 자산 구축을 목표로 합니다.

## 📌 주요 특징
1. **골격 수호:** 저작권 만료 공공재인 `<개역한글(1961)>`을 기초 대본으로 삼아 웅장한 낭독조 운율을 계승합니다.
2. **고어 완전 청산:** 현대 독자에게 오해를 주거나 읽기 힘든 고어/사어를 직관적인 현대 표준어로 완전 교정합니다.
3. **원어 검증:** 히브리어/헬라어 원문(BHS/NA28) 및 영문 WEB 대조를 통해 오역을 바로잡은 독자적 2차 저작물입니다.
4. **CC0 1.0 Universal:** 어떠한 저작권 제약도 없는 완전 퍼블릭 도메인 자산입니다.

## 📂 저장소 구조

- `/logs/` : 구절별 변환 사유 및 저작권 방어용 세부 개정 이력 (Commit Log)
